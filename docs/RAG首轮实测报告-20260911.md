## 3. 检索引用命中表现

- **中文问 5 题:命中 2/5(40%)**。空召回 3 题的知识(受限直接执行/地址空间/极限)实际都在库中。
- **英文问 2 题:命中 2/2**,引用文档全部正确(OSTEP-03、OSTEP-02),页码可用。
- **越界问 1 题:正确拒答**(防编造规则起效),但 references 仍带回 5 条不相关分块(过了阈值的噪声块进入了上下文),前端会显示无关来源。
- 引用标注一致性:答案中 `[n]` 标记数 ≈ references 条数(5/5、5/5、4/5、3/5),可追溯性正常。
- references 的 score 字段为 RRF 融合分(~0.016)而非向量相似度,前端若直接展示"相关度"会误导。

## 4. 空召回根因(经 debug 接口分阶段验证)

`GET /api/admin/kb/debug?question=...` 对照实验:

| 用例 | 召回 | 向量分 |
|------|------|--------|
| 中文问 LDE(阈值 0.5) | **0 条** | 全部 <0.5 |
| 英文问 LDE(阈值 0.5) | 20 条 | 0.63–0.68 |
| 中文问 LDE(阈值 0.3) | 20 条 | 0.486–0.495 |
| 英文问地址空间(阈值 0.5) | 20 条 | 0.636–0.683 |
| 中文问极限(阈值 0.3) | 20 条 | 0.395–0.41 |

根因三条,按贡献排序:
1. **跨语言向量分系统性压低**:bge-small-zh 对"中文问/英文档"的相似度集中在 0.40–0.53,比同概念英文问低约 0.15。
2. **阈值 0.5 恰好卡线**:中文问分数带上沿 ≈0.52,阈值 0.5 把整批结果砍成 0;降到 0.3 则 20 条全出。
3. **关键词路缺位**:query 含英文术语(如 "Limited Direct Execution")本可由 ngram 全文索引兜底,但索引未建,双路退化为单路,失去容错。

## 5. 修复建议(未执行,待决策)

1. 执行 `sql/upgrade_fulltext_index.sql` 建 ngram 全文索引,恢复混合检索双路兜底(对含英文术语的中文 query 直接有效)。
2. 默认相似度阈值 0.5 → 0.35~0.4,并开启重排(`RERANK_API_KEY` 复用嵌入 Key)精排补偿,兼顾噪声过滤。
3. 长期:教材以英文为主时,换多语言嵌入模型(bge-m3 / text-embedding-v3),注意换模型须删除旧 Collection 全量重建向量(README 七)。
4. 越界场景的 references 噪声:生成侧已正确拒答,可考虑回答为"暂无相关内容"时不返回 references,或按重排分二次过滤。
