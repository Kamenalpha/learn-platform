# 实现进展(Implementation Progress)

> 面向「通用多学科智能学习平台」毕设,记录已完成的功能模块、代码位置与论文章节映射,供写作与验收对照。

## 一、总体状态

- 后端:Spring Boot + Spring AI,已迁移至新库 `learn_platform`(32 张表),**离线编译通过(JDK17)**。
- 前端:Vue3 + Element Plus 响应式,新增 7 个核心页面,API/路由/菜单已就绪(本机构建受环境限制未验证,需 `npm run dev`)。
- 基础设施:MySQL `learn_platform` 已建库导入;Chroma 已用项目 venv(`.venv` 装 `chromadb`)在 127.0.0.1:8000 运行(数据 `data/chroma`);Redis(6379)与 LLM/Embed API Key 需另行提供(见 `scripts/start-infra.ps1`)。

## 二、后端模块(controller / service)

| 模块 | 接口前缀 | 主要文件 | 说明 |
|------|----------|----------|------|
| 认证 | `/api/auth` | `AuthController` | 注册/登录,角色(用户/管理员) |
| 学科 | `/api/subjects` | `SubjectController` | 分类顶层 |
| 课程 | `/api/courses` | `CourseController` | 二级分类,用户归属+公开可见 |
| 章节 | `/api/chapters` | `ChapterController` | 三级分类 |
| 知识点 | `/api/knowledge-points` | `KnowledgePointController` | 四级分类叶子 |
| 资源(资料) | `/api/docs` | `DocumentController` | 上传(PDF/Word/PPT/TXT+OCR)/解析/分块/预览/重解析/删除 |
| AI 助手 | `/api/assistants` | `AssistantController` | 助手定制+绑定课程(知识隔离) |
| 问答 | `/api/chat` | `ChatController` | RAG 问答,可限定助手课程+自定义提示词,引用溯源 |
| 学习计划 | `/api/plans` | `StudyPlanController` | 计划+任务,完成打卡埋点 |
| 社区 | `/api/community` | `CommunityController` | 帖子/问答/采纳/评论/点赞 |
| 出题模拟 | `/api/exam` | `ExamController` | 三出处自动出题/判分(客观+AI)/错题本 |
| 项目辅导 | `/api/projects` | `ProjectController` | AI 拆解→方案/任务/阶段/报告 |
| 学习画像 | `/api/analytics` | `AnalyticsController` | 时长/连续打卡/弱项统计 |
| 管理后台 | `/api/admin/*` | `Stats/Kb/User` 等 | 用户/审核/RAG参数/配额/看板 |
